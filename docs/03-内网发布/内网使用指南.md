# 内网使用指南

## 📌 配置说明

在内网机器上，配置 npm registry 指向本项目的 Verdaccio 仓库：

### 方式 1：全局配置（推荐）
```bash
npm config set registry http://localhost:4873
```

### 方式 2：项目级配置
在项目根目录创建 `.npmrc` 文件：
```
registry=http://localhost:4873
```

### 方式 3：临时使用
```bash
npm install --registry=http://localhost:4873
```

## 🔧 常见问题

### 1. 无法连接到 Verdaccio
- 确保 Verdaccio 服务正在运行：`npm start`
- 检查防火墙是否阻止了 4873 端口
- 确认地址是否正确：http://localhost:4873

### 2. 包不存在
- 确保包已成功发布到 Verdaccio
- 访问 http://localhost:4873 查看已发布的包列表

### 3. 认证失败
- 如果需要认证，先登录：`npm login --registry=http://localhost:4873`
- 默认配置允许匿名访问（access: $all）
