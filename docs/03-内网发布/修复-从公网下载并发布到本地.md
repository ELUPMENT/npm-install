## 🔄 完整工作流程

```
第1步：从公网下载
┌─────────────────────┐
│  package.json       │
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│  npm install        │ ← 从 https://registry.npmjs.org 下载
│  (PUBLIC_REGISTRY)  │    （因为本地 Verdaccio 是空的）
└──────────┬──────────┘
           ↓
┌─────────────────────┐

└──────────┬──────────┘

第2步：发布到本地
           ↓
┌─────────────────────┐
│  offline-packages   │ ← 同步到离线目录
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│  npm publish        │ ← 发布到 http://localhost:4873
│  (LOCAL_REGISTRY)   │    （现在本地有了这些包）
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│  Verdaccio Storage  │ ← 包存储在本地
└──────────┬──────────┘

第3步：内网使用
           ↓
┌─────────────────────┐
│  内网机器            │ ← 配置 registry 后直接从本地下载
│  npm install xxx    │    （无需访问公网）
└─────────────────────┘
```

## 💡 关键要点

### 为什么需要两个 Registry？

| 阶段 | 使用的 Registry | 原因 |
|------|----------------|------|
| **下载阶段** | `https://registry.npmjs.org` | 本地 Verdaccio 是空的，必须从公网获取 |
| **发布阶段** | `http://localhost:4873` | 将下载的包发布到本地，供内网使用 |
| **内网使用** | `http://<服务器IP>:4873` | 内网机器从本地 Verdaccio 下载，无需公网 |

### 符合用户偏好

✅ **绝不覆盖已存在的包**
- 发布前通过 HTTP HEAD 检查包是否存在
- 已存在的包自动跳过
- E409 错误作为二次确认

✅ **保证完整依赖链的完整性**
- 使用 `npm install` 自动解析所有层级的依赖
- 扫描 node_modules 获取完整依赖树
- 去重处理，避免重复
