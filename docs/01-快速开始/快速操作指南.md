# 🚀 快速操作指南

## 一键下载并发布到内网

```bash
# 方式 1：双击批处理文件（最简单）
download-and-publish.bat

# 方式 2：使用 npm 命令
npm run download-and-publish
```

## 内网机器配置

```bash
# 全局配置（推荐）
npm config set registry http://<服务器IP>:4873

# 验证配置
npm config get registry

# 测试安装
npm install lodash
```

## 查看已发布的包

**浏览器访问：**
```
http://localhost:4873
```

**命令行查询：**
```bash
npm view lodash --registry=http://localhost:4873
```

## 启动 Verdaccio 服务

```bash
# 方式 1
npm start

# 方式 2
start.bat
```

## 常见问题速查

| 问题 | 解决方案 |
|------|----------|
| Verdaccio 未启动 | 运行 `npm start` |
| 连接失败 | 检查防火墙，确认 IP 和端口 |
| 包不存在 | 确认已成功发布，访问 http://IP:4873 查看 |
| 认证失败 | 运行 `npm login --registry=http://IP:4873` |
